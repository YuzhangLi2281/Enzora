# Enzora 前端设计与运行状态约定

主版本为马卡龙色系，采用清晰黑体、青紫粉科学配色与矢量标注。保留 Atlas 蓝黑版本作对照，两种主题共享数据和行为。

## 色彩与文字

- 页面只有一条背景：近白 `#FCFDFF` → 浅蓝 `#F2F8FF` / `#ECF3FF` → 浅紫 `#EEE5F8`。背景放在包住三阶段的 `process-canvas` 上，阶段背景透明，滚动时没有色块接缝。
- 模型与科学图表分别使用灰青 `#8AC3C1`、灰紫 `#B497C7`、浅粉 `#F1C8DB`；分数图中的较深同色用于提高可读性。减少荧光绿。
- 面板轻、哑光，避免厚重金属反射。Assistant 保留更鲜明的青紫粉渐变、柔和高光与放大图标。
- 全站采用 Arial / Noto Sans SC / 苹方 / 微软雅黑无衬线，700 粗体。正文、注释、刻度、控件与等待状态均适用；不以模糊文字阴影制造立体感。
- 突变残基固定深蓝底白字；预测来源色与残基标记色分开。

## 三阶段与数据真实性

1. 建库：输入、参数、突变库三个固定翻转视图。实际生成器为 ProteinDPO、EnzGFM、VESM3，卡片可展开论文与接入边界。环形进度由已保存数量驱动；连接线脉冲频率对应实际保存速度，不以时间假装进度。
2. 评分：PheNom 活性、EpHod pH、UniStab 稳定性。逐步展示已有真实预测的直方图，不展示缺失模型分数。有效权重为 `normalize(preference × confidence)`；区分未应用/已应用/下轮设置，目标和阈值运行前固定；短屏参数区滚动，提交按钮保持可见。
3. 输出：全库嵌入图、Top-5 箭头、Top-K 详细表、全部替换残基、报告和 CSV/FASTA/CDS 导出。点击非 Top-K 节点时检查该库内序列，不错用第一候选。宿主支持 E. coli 与 Bacillus subtilis，同义优化不改变蛋白。

每个阶段完成后等待明确 Next。阶段导航仅切换视图。演示模式始终标记；模拟投影明确不是 UMAP，模拟分数不用于科研结论。真实模式只使用后端坐标和预测。最低校准 LLR 模型占比来自保存的替换位点，平局均分，并非生成因果贡献；只有收到至少两次真实快照后才绘制占比变化记录。

## 交互细节

- 桌面主容器高 `100dvh - header`，每个阶段同高；手机/平板允许内容纵向展开。滚轮自由滚动，Next 在主容器内精确整屏定位，避免小幅滚轮被浏览器吸附拉回。关闭滚动锚定以防数据更新跳页。
- 装饰图绝对定位、固定宽高比、层叠在内容后方，禁止接收指针事件。不能扩大主内容的横向滚动范围。
- UMAP 保留坐标几何，只移动摄像机。拖拽可从节点开始，4px 阈值区分点击；平移受边界约束，缩放 80%–800%，支持鼠标、方向键、+/− 与 0 复位。空地图不截获滚轮。工具栏避开可点击点。
- 顶部导航、主题、翻转标签、主要按钮、导出和阶段按钮有悬停、触碰压缩与弹性回位；减少动态效果系统偏好下停用位移动画。
- Enzora Assistant 可拖拽、折叠、用方向键移动；拖拽与屏幕缩放后保留在视口内。输入支持 Enter/Shift+Enter、中文输入法、请求等待、重试及返回的 CDS 导出；Esc 收起后焦点回到切换按钮。
- 手机保留页面菜单、设置入口与演示切换；图表跨整行，避免三列挤压成不可读缩略图。

## 素材来源

`models/*.svg` 为自绘模型概念图；GitHub 图标使用用户指定的 `fonts/github.png`。


## 验证边界

回归与浏览器检查应覆盖 1440×900、1366×768、768×1024、390×844，两种语言/主题、两次 Next、dirty→applied、模型等待/运行/完成、节点拖拽/缩放/点选、Assistant 拖动/键盘、离线错误与四类下载。实际下载的 CDS 需翻译核验。

Taste skill 的营销页启发式不能替代科研工作台检查：用户明确要求渐变、浅紫、科学细线/表格与果冻反馈；页面不为满足图片/视频数量而加入无关素材。仍检查真实的溢出、坏图、对比度和标题换行。当前真实 GPU 推理、Gemini 在线鉴权及服务器部署均待验证，不以演示代替。
